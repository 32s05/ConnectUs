<h1 align="center">ConnectUs</h1>

## Project Overview

**ConnectUs** is a dynamic platform built to seamlessly connect individuals seeking services with providers ready to offer their expertise. Designed for both customers looking for reliable help and providers aiming to expand their reach, ConnectUs simplifies the way people discover, offer, and manage services — all in one accessible and user-friendly space.

## Features

### Seeker (Customer) Side
- **Register and Login**
- **Book services**
- View updates about their booked services (Pending, Accepted, Finished, or Ongoing)

### Provider Side
- **Register and Login**
- **Track their bookings**
- **Track their earnings**
- Update and manage bookings from seekers (Accept, Decline, Mark as Complete)

## Usage Guide

### For Seekers
1. Register and create an account.  
2. Book available services, selecting your preferred date and time.  
3. Go to **"My Bookings"** to view current and past bookings.  
4. User can cancel their booked service if it's still pending
5. Go to **"Edit Profile"** to edit user information

### For Providers
1. **Register** and create an account.  
2. **Register the service** being provided.  
3. Go to **"Booking Requests"** to manage incoming requests.  
   - Accept, Decline, or Mark as Complete.  
4. View past services in **"Completed Bookings"**.  
5. Edit details under **"Edit Service"** or **"Edit User Profile"**.

## How to Run the Project

1. **Download or clone** the project.
2. Open Command Prompt or Terminal and run:
    *cd project-name*
    *code .*
3. Install dependencies:
    *npm install*
4. Start the development server:
    *npm start*
    - By now, the website should be running on localhost:3000/page
5. Enjoy the website!
